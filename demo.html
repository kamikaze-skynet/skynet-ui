Accordion

Built on the native <details> element — zero JavaScript. Add open to expand one by default.

Does it need any JavaScript?
No — the accordion uses the browser's built-in <details>/<summary> elements, so it works even before skynet-ui.js loads.
Can several stay open at once?
Yes, each accordion is independent. If you want exclusive behavior, give them the same name attribute (modern browsers close the others automatically).
How do I style the body?
Put your content in a .sk-accordion-body div right after the summary — anything can go inside.
