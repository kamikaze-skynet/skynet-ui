Changelog

Pinned versions stay available forever at /vX.Y.Z/.

v3.0.0 — “The AI App Kit”
Chat kit, prose, MCP server, and 15+ new components
  • sk-prose typography for rendered markdown / LLM output; chat kit (bubbles, typing dots, prompt bar) + skTypewriter
  • Combobox, date picker, dual-handle range, number stepper, star rating, banner, lightbox, onboarding tour (skTour)
  • Tables: row selection + bulk bar, CSV export, sticky headers, stat deltas
  • A11y: focus trap in overlays, ARIA wiring, contrast theme (9th), data-theme="auto", compact density, print styles
  • MCP server at /mcp; minified files + SRI hashes per release; examples gallery, theme builder, this changelog
v2.1.0
Tag input, tree view, context menus, table pagination

Plus the mobile dropdown-overflow fix and cache-busted deploys with visible build stamps.

v2.0.0
Tailwind-compat utility layer + LLM-first landing

~170 Tailwind-named utilities with sm:/md:/lg: variants, the Tailwind conversion guide in llms.txt, and skynetui.com built around LLM prompts.

v1.5.0
Four new themes

Forest and dusk (dark family), sky and rose (light family) — eight built-ins.

v1.4.0
Midnight & paper themes, form validation, skPrompt

Theme picker with persistence, autogrow textareas, character counters, scroll reveal, carousel autoplay.

v1.3.0
Command palette, popovers, carousel, toast actions

Ctrl+K palette with keyboard nav; themed native date inputs via color-scheme.

v1.2.0
Drawers, stepper, timeline, sortable/filterable tables

Plus skConfirm, segmented controls, scrollspy, and avatar groups.

v1.1.0
11 new components + theme toggle

Breadcrumbs, pagination, accordion, tooltips, skeletons, chips, hero, footer, and more.

v1.0.0
Initial release

The original two-file dark-first kit: 17 component families, utilities, light theme.
